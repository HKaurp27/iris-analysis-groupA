# Reflection

Working on my Iris dataset project was definitely a learning curve, though I figured it out piece by piece. 

I won't lie, GitHub was a huge headache in the beginning. Just trying to wrap my head around basic git commands, pushing and pulling without accidentally messing up my files, and dealing with initial merge conflicts felt pretty overwhelming. Once I finally got the hang of the repository workflow, though, it made managing everything a lot easier.

After getting past that initial hurdle in Phase 1, the actual coding started to click. In Phase 2, I focused on Python basics by writing loops, setting up variables for petal and sepal measurements, and building custom functions to classify the flowers. By Phase 3, I was really digging into data cleaning inside my Jupyter Notebook, using pandas to check for missing values, exporting my cleaned dataset, and generating a summary text report. I wrapped everything up in Phase 4 with data visualization, putting together charts and plots to compare species averages and look at data distributions.

Now that I survived the initial GitHub struggle and figured out how to handle my workflow, I feel a lot better about future projects. Knowing how to actually manage a repo and work through code without panicking is going to make tackling the next assignments so much smoother. It was a lot of work, but it felt like a solid intro to how real data science tasks actually operate.
